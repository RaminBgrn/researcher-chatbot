# Constitution — Researcher Chatbot

اصول حاکم بر این پروژه؛ هر فیچر باید با این اصول سازگار باشد.

1. **سادگی اول است.** این یک پروژه آموزشی است: بدون فریم‌ورک سنگین، بدون دیتابیس، بدون وابستگی غیرضروری. هر پیچیدگی تازه باید دلیل آموزشی یا کاربردی روشن داشته باشد.
2. **سه مفهوم اصلی جدا می‌مانند.** سیستم پرامپت در `prompts.py`، ابزارها در `tools.py`، هیستوری و حلقه tool call در `chatbot.py`. فیچر جدید این مرزها را به هم نمی‌ریزد.
3. **کلید و راز در کد و گیت نیست.** اتصال مدل فقط از `.env` خوانده می‌شود و `.env` هرگز کامیت نمی‌شود.
4. **مستندات عمومی فقط درباره خود پروژه‌اند.** README و فایل‌های داخل ریپو فرایند ساخت و همکاری را روایت نمی‌کنند.
5. **تمام‌شده یعنی تست‌شده.** هر تغییر با تست واقعی (حداقل تست API و باز شدن صفحه) راستی‌آزمایی می‌شود، نه با حدس.
6. **دسترسی‌پذیری پایه رعایت می‌شود.** کنتراست کافی در هر دو تم، فوکوس قابل مشاهده، و اندازه لمس مناسب برای دکمه‌ها.
