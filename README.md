# Researcher Chatbot — چت‌بات پژوهشگر

یک چت‌بات ساده برای تمرین سه مفهوم:
**Tool Call** + **مدیریت سیستم پرامپت** + **مدیریت هیستوری**

کاربر یک موضوع می‌دهد → بات در ویکی‌پدیا تحقیق می‌کند → گزارش می‌نویسد → گزارش را در یک فایل داخل `outputs/` ذخیره می‌کند.

## ساختار پروژه

| فایل | نقش |
|---|---|
| `app.py` | سرور Flask؛ صفحه چت و دو API ساده |
| `chatbot.py` | مغز بات: هیستوری + حلقه اجرای tool call ها |
| `prompts.py` | فقط سیستم پرامپت — تنها جای تغییر رفتار بات |
| `tools.py` | ابزارها: `search_wikipedia` (تحقیق) و `save_research` (ذخیره فایل) |
| `templates/index.html` | صفحه چت |
| `static/style.css` | دیزاین مدرن صفحه |
| `static/app.js` | فرستادن پیام و نمایش جواب |
| `.env` | کلید و endpoint و اسم مدل (از `.env.example` بساز؛ با کسی شریک نشو) |
| `outputs/` | گزارش‌های ذخیره‌شده اینجا می‌آیند |

## اجرا

```bash
pip install -r requirements.txt
# فایل .env.example را کپی کن به .env و مقادیر API_KEY و BASE_URL و MODEL_NAME را پر کن
python app.py
```

بعد در مرورگر: http://localhost:5000
